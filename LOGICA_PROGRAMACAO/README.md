# 🐍 Plano de Aula: Lógica de Programação com Python

## 1. Fundamentos da Linguagem Python
### Conceitos Iniciais
* **Sintaxe:** Uso de indentação obrigatória para definição de blocos de código.
* **Variáveis:** Armazenamento dinâmico de dados sem necessidade de declarar tipos.
* **Tipos Primitivos:** `int` (inteiros), `float` (decimais), `str` (textos) e `bool` (booleanos).

### Estruturas de Controle e Dados
* **Condicionais:** Tomada de decisão usando as estruturas `if`, `elif` e `else`.
* **Repetição:** Laços de iteração em coleções e blocos utilizando `while` e `for`.
* **Coleções:** Manipulação de dados estruturados com listas, tuplas e dicionários.

## 2. Controle de Versão com Git e GitHub
### Git (Local)
* **Conceito:** Sistema de controle de versão distribuído para rastrear mudanças.
* **Comandos Essenciais:**
  * `git init`: Inicializa um repositório na pasta local.
  * `git add`: Adiciona arquivos para a área de preparação (*staging area*).
  * `git commit -m "mensagem"`: Grava a foto do estado atual do código.

### GitHub (Remoto)
* **Conceito:** Plataforma em nuvem para hospedar e compartilhar repositórios Git.
* **Fluxo de Trabalho:**
  * `git remote add origin url`: Vincula o código local ao servidor.
  * `git push`: Envia as alterações locais para o repositório online.
  * `git pull`: Baixa as atualizações da nuvem para a máquina local.

## 3. Código Limpo (Clean Code) em Python
### Princípios de Legibilidade
* **Nomes Significativos:** Variáveis e funções devem revelar claramente a sua intenção.
* **Regra do Escoteiro:** Deixe sempre o código mais limpo do que como você o encontrou.
* **Funções Pequenas:** Devem fazer apenas uma coisa e possuir poucas linhas de código.

### Boas Práticas Pythonicas
* **PEP 8:** Guia de estilo oficial para escrita de código na linguagem Python.
* **Comentários:** Usar apenas quando o código não for capaz de se explicar sozinho.
* **Tratamento de Erros:** Uso correto de blocos `try` e `except` para evitar falhas.

## 4. Desenvolvimento de Projetos Práticos
### Diretrizes para os Alunos
* **Escopo:** Aplicação real dos conceitos de lógica, versionamento e Clean Code.
* **Entregáveis Obrigatórios:**
  * Código fonte estruturado em funções reutilizáveis.
  * Repositório público no GitHub com histórico de commits frequentes.
  * Arquivo `README.md` explicando o funcionamento e como rodar o projeto.

### Sugestões de Projetos Acadêmicos
1. **Calculadora de Terminal:** Uso de condicionais, laços e funções limpas.
2. **Sistema de Cadastro de Clientes:** Manipulação de dicionários e listas.
3. **Simulador de Caixa Eletrônico:** Lógica avançada de controle e tratamento de erros.
